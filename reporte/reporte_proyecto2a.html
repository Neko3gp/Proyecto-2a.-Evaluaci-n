Proyecto 2a. Evaluación — BDAutos en MongoDB

Universidad Autónoma de Chihuahua — Bases de Datos Avanzado

Generado: 2026-11-02 14:00

Base: bdautos — colecciones: continents, countries, makers, cars

1. Objetivo

Aplicar Aggregation Framework: diseñar BD Autos con embedding y linking, migrar desde el modelo relacional, resolver 25 consultas y exponerlas con una aplicación Python que muestra el código y el resultado.

2. Modelo documental

  • continents: catálogo (linking target).
  • countries: linking continentId + snapshot embebido.
  • makers: embedding de models[] + linking countryId.
  • cars: embedding Names+Details + snapshots + linking makerId/modelId.

Detalle en docs/01_modelo_y_migracion.md.

3. Migración

Script scripts/migrate.py parsea data/BDAutosU2.sql e inserta documentos. Conteos esperados: 5 / 17 / 20 / 42 modelos / 138 autos.

{
  "continents": 5,
  "countries": 17,
  "makers": 20,
  "cars": 138
}
